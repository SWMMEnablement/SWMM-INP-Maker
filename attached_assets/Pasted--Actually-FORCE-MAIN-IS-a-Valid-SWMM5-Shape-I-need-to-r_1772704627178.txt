## Evidence from SWMM5 Documentation

### 1. EPA SWMM5 Help File (Cross-Section Editor)

> *"The **Force Main** shape option is a circular conduit that uses either the Hazen-Williams or Darcy-Weisbach formulas to compute friction losses for pressurized flow during Dynamic Wave flow routing. In this case the appropriate C-factor (for Hazen-Williams) or roughness height (for Darcy-Weisbach) is supplied as a cross-section property."*

### 2. SWMM5 Routing Options

> *"Selects which equation will be used to compute friction losses during pressurized flow for conduits that have been assigned a **Circular Force Main cross-section**."*

### 3. From OpenSWMM Forum (Robert Dickinson's own posts)

> *"SWMM 5 uses either the HW or DW friction slope if the **Force Main is full** or Manning's n if the non-Force Main is full or the Force Main is **partially full**."*

### 4. Types of Force Mains in SWMM5

> *"There are **five ways** to model a force main in SWMM 5:*
> *1. Full Flow using Darcy-Weisbach for the friction loss*
> *2. Full Flow using Hazen-Williams for the friction loss*
> *3. Full Flow using Manning's n for the friction loss*
> *4. Partial Flow uses Manning's n"*

## How FORCE_MAIN Works in [XSECTIONS]

```ini
[XSECTIONS]
;;Link           Shape        Geom1    Geom2    Geom3   Geom4   Barrels
;;                            Diam     Rough
Conduit_1        CIRCULAR     1.5      0        0       0       1
ForceMain_1      FORCE_MAIN   0.6      130      0       0       1
```

| Parameter | CIRCULAR | FORCE_MAIN |
|---|---|---|
| **Geom1** | Diameter | Diameter (identical) |
| **Geom2** | 0 (not used) | **C-factor (H-W) or roughness height (D-W)** |
| **Geometry** | Circle | Circle (identical shape) |
| **Friction (partial flow)** | Manning's n | Manning's n (identical) |
| **Friction (full/pressurized)** | Manning's n | **Hazen-Williams or Darcy-Weisbach** |
| **Roughness source** | [CONDUITS] Manning's n | [XSECTIONS] Geom2 + [CONDUITS] Manning's n |

**The key difference:** When the pipe is pressurized (surcharged), FORCE_MAIN switches from Manning's to H-W or D-W. CIRCULAR keeps using Manning's even under pressure.

## Why Both Exist (and Both Are Correct)

```
CIRCULAR pipe under pressure:
  Sf = (n·Q / (A·R^(2/3)))²     ← Manning's always

FORCE_MAIN pipe under pressure:
  Sf = (Q / (0.432·C·D^2.63))^1.852   ← Hazen-Williams (when full)
  Sf = (n·Q / (A·R^(2/3)))²            ← Manning's (when partial)
```

This is explicitly stated:

> *"Note that a conduit does not have to be assigned a Force Main shape for it to pressurize. Any of the other closed cross-section shapes can potentially pressurize and thus function as force mains **using the Manning equation** to compute friction losses."*

So:
- **CIRCULAR** can pressurize → uses Manning's for friction
- **FORCE_MAIN** can pressurize → uses H-W or D-W for friction (more accurate for pressurized pipe flow)

## The Valid INP Format

Here's what a properly formatted force main looks like in an .inp file:

```ini
[OPTIONS]
FORCE_MAIN_EQUATION  H-W          ;; or D-W

[CONDUITS]
;;Name    From    To      Length  Roughness  InOffset  OutOffset
FM_1      J5      J6      500     130        0         0

[XSECTIONS]
;;Link    Shape        Geom1   Geom2   Geom3   Geom4   Barrels
FM_1      FORCE_MAIN   0.6     130     0       0       1
```

Note the important detail: **the Roughness in [CONDUITS] for a FORCE_MAIN is the C-factor (for H-W) or roughness height in mm (for D-W)**, not Manning's n. This is different from CIRCULAR where Roughness = Manning's n.

Your [OPTIONS] section also needs:
```ini
FORCE_MAIN_EQUATION  H-W    ;; Hazen-Williams
;; or
FORCE_MAIN_EQUATION  D-W    ;; Darcy-Weisbach
```
