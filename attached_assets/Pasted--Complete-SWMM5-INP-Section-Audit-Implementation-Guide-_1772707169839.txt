```

;;Name           Type
;;               Parameters...

BioRetention     SURFACE    150    0.0    0.1    1.0    5

BioRetention     STORAGE    300    0.75   0.5    0
BioRetention     DRAIN      25     0.5    6      6      0    0

TYPES TO GENERATE:
  BC  — Bio-Retention Cell        (most common)
  PP  — Permeable Pavement
  IT  — Infiltration Trench
  RB  — Rain Barrel
  RG  — Rain Garden (5.2+)
  GR  — Green Roof
  VS  — Vegetative Swale
  RD  — Rooftop Disconnection

SUGGESTED DISTRIBUTION (from real models):
  Bio-Retention:     35%
  Permeable Pave:    20%
  Rain Barrel:       15%
  Green Roof:        10%
  Inf. Trench:       10%
  Veg. Swale:         5%
  Rain Garden:        5%

EFFORT: Medium
IMPACT: ⭐⭐⭐⭐⭐ (highest demand feature)
```

### 2. [LID_USAGE] — LID Placement on Subcatchments

```
WHY: Companion to [LID_CONTROLS] — specifies which subcatchments
     use which LID controls and at what scale.

FORMAT:
[LID_USAGE]
;;Subcatch   LID          Number  Area    Width  InitSat  FromImp  ToPerv  RptFile  DrainTo  FromPerv
S1           BioRetention  3      200     0      0        25       1       *        *        0

GENERATION LOGIC:
  - Apply LID to X% of subcatchments (user parameter, default 30%)
  - Select LID type based on land use:
      Residential → Rain Barrel, Rain Garden
      Commercial  → Green Roof, Permeable Pavement
      Industrial  → Infiltration Trench
      Mixed       → Bio-Retention
  - Size LID area as 5-15% of subcatchment impervious area
  - Number of units = LID_area / single_unit_area

EFFORT: Medium (depends on LID_CONTROLS)
IMPACT: ⭐⭐⭐⭐⭐
```

### 5. [BUILDUP] — Pollutant Accumulation on Land Surfaces

```
WHY: Defines how pollutants accumulate during dry weather.
     Part of the LANDUSE → BUILDUP → WASHOFF → POLLUTANT chain.

FORMAT:
[BUILDUP]
;;LandUse       Pollutant  Function  Coeff1   Coeff2    Coeff3   PerUnit
Residential     TSS        SAT       50       0         2.0      AREA
Residential     BOD        SAT       25       0         3.0      AREA
Commercial      TSS        SAT       80       0         1.5      AREA
Commercial      BOD        SAT       40       0         2.0      AREA
Industrial      TSS        SAT       120      0         1.0      AREA
OpenSpace       TSS        SAT       20       0         5.0      AREA

BUILDUP FUNCTIONS:
  POW:  B = Min(C1, C2·t^C3)           Power function
  EXP:  B = C1·(1 - exp(-C2·t))        Exponential
  SAT:  B = C1·t / (C2 + t)            Saturation
  EXT:  B = from external time series

TYPICAL VALUES (kg/ha):
  Pollutant   Residential  Commercial  Industrial  OpenSpace
  TSS         50           80          120         20
  BOD         25           40          60          10
  TN          5            8           12          3
  TP          1            2           3           0.5

EFFORT: Medium
IMPACT: ⭐⭐⭐⭐
```

### 6. [WASHOFF] — Pollutant Removal by Runoff

```
WHY: Companion to [BUILDUP] — defines how accumulated pollutants
     are washed off during rain events.

FORMAT:
[WASHOFF]
;;LandUse       Pollutant  Function  Coeff1   Coeff2   SweepRmvl  BmpRmvl
Residential     TSS        EXP       0.012    1.8      0.7        0.0
Residential     BOD        EXP       0.012    1.8      0.5        0.0
Commercial      TSS        EXP       0.015    1.8      0.8        0.0
Industrial      TSS        EXP       0.020    1.8      0.6        0.0

WASHOFF FUNCTIONS:
  EXP:  W = C1·q^C2·B         Exponential (most common)
  RC:   W = C1·q^C2            Rating curve
  EMC:  W = C1                 Event mean concentration

  where q = runoff rate, B = current buildup

TYPICAL VALUES:
  C1 (washoff coefficient): 0.005-0.05
  C2 (washoff exponent):    1.5-2.5
  SweepRmvl:                0.5-0.9 (street sweeping efficiency)

EFFORT: Medium
IMPACT: ⭐⭐⭐⭐
```

### 11. [TREATMENT] — Water Quality Treatment at Nodes

```
FORMAT:
[TREATMENT]
;;Node       Pollutant   Function
WTP1         TSS         R = 0.85                ;; 85% removal
WTP1         BOD         R = 0.90                ;; 90% removal  
Pond1        TSS         C = 20 * exp(-0.1*HRT)  ;; function of HRT
BMP1         TSS         R = 1 - exp(-0.5*DT)    ;; first-order

TREATMENT EXPRESSIONS:
  R = fractional removal (0 to 1)
  C = effluent concentration
  Variables: HRT (hydraulic retention time), DT (detention time),
             FLOW, DEPTH, AREA, and any pollutant concentration

GENERATION:
  Apply to Storage nodes that act as treatment facilities
  Default: R = 0.6-0.9 for TSS, R = 0.5-0.8 for BOD

EFFORT: Medium
IMPACT: ⭐⭐⭐
```

### 13. [DIVIDERS] — Flow Splitting Nodes

```
FORMAT:
[DIVIDERS]
;;Name    Elev   DivLink   Type      Param1  Param2  Param3  ...
D1        100.0  C_bypass  OVERFLOW
D2        95.0   C_divert  CUTOFF    5.0
D3        90.0   C_split   TABULAR   DivCurve1
D4        85.0   C_frac    WEIR      3.0     2.5     0.0

TYPES:
  CUTOFF    — diverts all flow above cutoff value
  OVERFLOW  — diverts all flow above node's full depth
  TABULAR   — diversion based on curve (inflow vs diverted flow)
  WEIR      — side-flow weir diversion

WHY: Essential for CSO modeling, bypass channels, combined sewer regulators

GENERATION:
  For Combined Sewer models: add 1 divider per ~50-100 junctions
  For Storm: add at major branch points
  For Sanitary: rarely needed (0-1)

EFFORT: Medium
IMPACT: ⭐⭐⭐ (critical for combined sewer models)
```
