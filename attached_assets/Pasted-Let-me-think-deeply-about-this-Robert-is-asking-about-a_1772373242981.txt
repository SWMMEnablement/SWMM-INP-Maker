## Category 1: Tree-Growing Algorithms

These all start at the outfall and grow the network upstream, which mirrors how real collection systems actually drain.

### 1. Recursive Upstream Branching (Horton-Strahler)
```
Outfall → Trunk → Branches → Tributaries → Leaf nodes
```
Uses **Horton stream ordering** from geomorphology. Start at the outfall (order 1), branch into two order-2 streams, each branches into order-3, etc. The branching ratio, length ratio, and area ratio are all well-studied power laws.

**Why it works for SWMM:** Real sewer systems follow the same dendritic patterns as river networks because they're designed to mimic gravity drainage. Pipe diameters decrease with stream order exactly like channel width decreases upstream.

**Key parameters:**
- Bifurcation ratio (Rb ≈ 3–5 for sewers)
- Length ratio (Rl ≈ 1.5–3)
- Area ratio (Ra ≈ 3–6)
- Maximum stream order (determines network size)

```python
def grow_horton_network(outfall, max_order=5, Rb=4, Rl=2.0):
    """Grow network upstream using Horton ratios."""
    nodes = [outfall]
    links = []
    
    def branch(parent_node, order, direction_angle, length):
        if order > max_order:
            return
        
        # Number of tributaries at this order
        n_branches = round(Rb ** (max_order - order))
        branch_length = length / Rl
        
        for i in range(min(n_branches, 3)):  # max 3-way branch
            angle = direction_angle + (i - 1) * (60 + random(-15, 15))
            child = create_junction(
                parent=parent_node,
                distance=branch_length,
                angle=angle,
                depth_drop=branch_length * slope_for_order(order)
            )
            pipe = create_conduit(
                child, parent_node,
                diameter=diameter_for_order(order),
                length=branch_length,
                roughness=0.013
            )
            nodes.append(child)
            links.append(pipe)
            branch(child, order + 1, angle, branch_length)
    
    branch(outfall, 1, 0, initial_trunk_length)
    return nodes, links
```

### 2. L-System (Lindenmayer System) Grammar
Formal grammars that generate branching structures. Used for plant growth simulation since the 1960s — **perfectly suited for dendritic pipe networks**.

**Grammar rules for a sewer system:**
```
Axiom:    O          (outfall)
Rule 1:   O → T[+B][-B]    (outfall grows trunk, branches left and right)
Rule 2:   T → C T          (trunk extends with conduit)
Rule 3:   B → C [+B][-B]   (branch extends, may sub-branch)
Rule 4:   C → J—J          (conduit = junction to junction)

Symbols:
  O = outfall
  T = trunk segment
  B = branch segment  
  C = conduit
  J = junction
  + = turn left 30-60°
  - = turn right 30-60°
  [ = push state (save position/angle)
  ] = pop state (return to saved)
```

**Iterations control network size:**
- 3 iterations → ~20 nodes (small test model)
- 5 iterations → ~100 nodes (neighborhood)
- 7 iterations → ~500 nodes (small city)
- 9 iterations → ~2000+ nodes (full system)

**Why it's powerful:** You can encode **different sewer topologies as different grammars** — grid systems, radial systems, interceptor-with-laterals, all just different rule sets. The grammar is the "DNA" of the network type.

### 3. Space Colonization Algorithm
Originally developed for simulating tree crown growth. Scatter **attractor points** (representing service areas/parcels) across a terrain, then grow pipes from the outfall toward the attractors.

```
1. Place outfall at lowest point
2. Scatter N attractor points across the service area
3. Find nearest attractor to any existing network node
4. Grow a pipe segment toward that attractor
5. When a pipe reaches within radius R of an attractor, "consume" it
6. Repeat until all attractors consumed
```

**Why it's realistic:** The attractors represent real demand points (houses, buildings). The algorithm naturally creates networks that **serve all customers with minimum pipe length** — which is exactly what real engineers optimize for.

**SWMM relevance:** Each consumed attractor becomes a subcatchment outlet node. Pipe diameters are sized by cumulative upstream attractor count (= population served).

---

### 4. Diffusion-Limited Aggregation (DLA)
A particle physics model: random walkers (representing flow paths) stick when they touch the growing network. Creates fractal, branching structures with **realistic tortuosity**.

```
1. Seed the outfall as the initial cluster
2. Release a random walker from a distant point
3. Walker moves randomly until it touches the network
4. It sticks → becomes a new junction + conduit
5. Repeat 1000s of times
```

**Network properties:** DLA networks have fractal dimension ≈ 1.7, which is close to real drainage networks (D ≈ 1.6–1.8). They naturally avoid crossing, create realistic branch angles, and have power-law distributed pipe lengths.

---

### 5. Minimum Spanning Tree + Steiner Tree
Pure graph theory approach:

```
1. Place N junction locations (grid, random, or from real data)
2. Set outfall as root
3. Compute Minimum Spanning Tree (Kruskal's or Prim's)
4. Optimize with Steiner points (additional junctions that reduce total pipe length)
5. Orient all edges toward outfall (downhill)
6. Size pipes by accumulated upstream area
```

**Variants:**
- **Euclidean MST** — shortest total pipe length
- **Rectilinear MST** — pipes only run N-S or E-W (Manhattan grid cities)
- **Degree-constrained MST** — no node has more than K incoming pipes
- **Weighted MST** — edge weights include elevation change, not just distance

## Category 2: Terrain-Driven Approaches

### 6. DEM Flow Accumulation
Use a **Digital Elevation Model** to derive the network exactly how nature would drain the landscape.

```
1. Load DEM (real or synthetic)
2. Fill sinks (depressionless DEM)
3. Compute flow direction (D8 or D-infinity)
4. Compute flow accumulation
5. Threshold: cells with accumulation > T become pipe segments
6. Place junctions at confluences
7. Place outfall at pour point
8. Size pipes by upstream contributing area
```

**This is the most physically realistic method.** The network follows actual terrain. Pipe slopes match natural grade. Subcatchments are true topographic watersheds.

**Tools:** GRASS GIS`r.watershed`, WhiteboxTools, PySheds, TauDEM — all can produce the drainage network. You just convert to SWMM .inp format.

```python
import pysheds
from pysheds.grid import Grid

grid = Grid.from_raster('dem.tif')
dem = grid.read_raster('dem.tif')
pit_filled = grid.fill_pits(dem)
flooded = grid.fill_depressions(pit_filled)
inflated = grid.resolve_flats(flooded)
fdir = grid.flowdir(inflated)
acc = grid.accumulation(fdir)

# Extract network where accumulation > threshold
branches = grid.extract_river_network(fdir, acc > 500)
# Convert branches → SWMM junctions + conduits
```

### 7. Terrain Carving with Cost Surface
Instead of following natural drainage, **carve the most cost-effective pipe routes** through the terrain:

```
1. Define outfall location
2. Define service area boundary
3. Create cost surface: 
   - Low cost: downhill, along roads, through easements
   - High cost: uphill, through buildings, crossing utilities
4. Use least-cost path algorithm (Dijkstra on raster)
5. Route trunk line on lowest-cost path from farthest point to outfall
6. Route laterals from each block to nearest trunk node
```

**This mimics how real engineers actually design systems** — they route pipes along streets, avoid obstacles, minimize excavation by following grade.

### 8. Voronoi Tessellation → Dual Graph
```
1. Place junction points (on a grid, random, or from addresses)
2. Compute Voronoi tessellation → each cell is a subcatchment
3. The dual graph (Delaunay triangulation) gives potential pipe routes
4. Prune to a tree rooted at the outfall
5. Each Voronoi cell becomes a SWMM subcatchment
6. Each dual edge becomes a conduit
```

**Why it's elegant:** Subcatchments and the pipe network are generated simultaneously from the same point set. The Voronoi areas give realistic subcatchment shapes and areas. Thiessen polygons are already used in hydrology for rainfall interpolation.

## Category 4: Procedural Generation (Game Dev Techniques)

### 13. Wave Function Collapse (WFC)
Originally for procedural level generation in games. Define **tiles** that represent sewer network segments:

```
Tile types:
  [Straight]     J—————J          (pipe continues)
  [Branch-L]     J—————J          (pipe branches left)
                   \
                    J
  [Branch-R]      J              (pipe branches right)
                  /
               J—————J
  [T-junction]    J              (three-way)
                  |
               J——J——J
  [Bend-L]     J                 (pipe turns left)
                \
                 J
  [End-cap]    J—— (terminal node, add subcatchment)
  [Pump]       J—P—J             (pump station)
  [Storage]    J—[S]—J           (storage node)

Adjacency rules:
  - Straight connects to Straight, Branch, Bend
  - Branch connects to Straight on all 3 ports
  - End-cap connects to anything on one side only
  - All tiles must maintain downhill flow toward outfall
```

**Start with outfall tile, collapse wave function outward.** The adjacency rules guarantee connectivity. The elevation constraint guarantees flow direction. Tile probabilities (from your real-model statistics) guarantee realism.

### 15. Cellular Automata

Run until stable. The emergent pattern is a sewer network. Different rule sets produce different topologies — grid networks, radial networks, interceptor patterns.

### 17. Optimal Channel Network (OCN)
From Rodriguez-Iturbe & Rinaldo's groundbreaking work on river networks. The principle: **nature minimizes total energy dissipation**.

```
Objective: Minimize Σ (Ai^γ × Li) for all links i
Where:
  Ai = upstream contributing area of link i  
  Li = length of link i
  γ = 0.5 (Hack's exponent)

Algorithm:
  1. Start with random spanning tree on grid
  2. Perturb (swap edges)
  3. Accept if total energy decreases (simulated annealing)
  4. Converge to optimal network
```

OCNs reproduce the statistical properties of real river networks (and by extension, sewer networks) from first principles. They've been validated against thousands of real catchments worldwide.

### 19. Gravity-Based Attraction Model
Nodes attract pipes proportional to their "mass" (flow demand) and inversely proportional to distance squared:

```
F_ij = G × (demand_i × capacity_j) / distance_ij²
```

Start with outfall, iteratively connect the most attracted unconnected node. This naturally produces networks where **dense areas get more direct connections** and sparse areas connect via longer laterals — matching real engineering practice.
