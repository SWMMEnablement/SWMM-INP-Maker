🌊 Overview

▼

The SWMM5 Model Generator creates realistic synthetic EPA SWMM5 .inp files of any size using a physics-based force-directed network synthesis engine. Every parameter, probability, and distribution is derived from statistical analysis of 338 real-world models containing 3,009,909 elements and 1,268,875 cross-sections from the SWMMEnablement/1729-SWMM5-Models GitHub repository.

Instead of random placement, the generator uses a Barnes-Hut quadtree particle simulation where nodes settle along terrain flow paths via gravitational pull, inter-particle repulsion, and outfall attraction — producing naturally dendritic drainage networks.

⚙️ Generation Pipeline

▼

Phase 0 — Terrain & Initialization

A synthetic DEM is created using 5-octave fractal Brownian motion noise with a base slope toward outfall points. N particles (future junctions) are scattered randomly across the domain. Domain size scales as √N × avg_conduit_length.

Phase 1 — Barnes-Hut Particle Simulation

Each iteration builds a quadtree for O(N log N) repulsion. Three forces act on each particle:

ForcePurposeAlgorithm
RepulsionPrevents clustering, creates spacingBarnes-Hut traversal (θ = 0.7)
Terrain gradientPushes particles downhill along DEMFinite-difference gradient
Outfall attractionWeak pull toward discharge pointsInverse-distance weighting

Updates via dual descent: v = momentum × v + F × dt, with cooling.

Phase 2 — Dendritic Topology

Each junction connects to the neighbor with the steepest elevation descent — producing tree-shaped networks where all paths converge at outfalls.

Phase 3 — Parameter Assignment

DEM elevations map to the user's terrain range. Pipe diameters scale with upstream accumulation count. The 338-model rules engine assigns offsets, shapes, roughness, DWF, pump curves, and controls.
