Quick Start
# Generate a 500-node stormwater model
curl -X POST /api/generate \
  -H "Content-Type: application/json" \
  -d '{"N": 500, "type": "stormwater", "terrain": "moderate"}'

# Generate and get raw .inp file
curl -X POST "/api/generate?format=inp" \
  -H "Content-Type: application/json" \
  -d '{"N": 200, "type": "sanitary"}' -o model.inp

# Generate from a preset
curl "/api/presets/Small%20Residential%20Sanitary?generate=true&format=inp" -o model.inp

# Generate, simulate, and get results in one call
curl -X POST /api/generate-and-simulate \
  -H "Content-Type: application/json" \
  -d '{"N": 300, "type": "combined", "enableWQ": true}'

        POST
        /api/generate
        Generate a SWMM5 .inp file from configuration
        ▶
      

      

        
Generates a complete EPA SWMM5 .inp file based on the provided configuration. All parameters are optional and default to a 200-node sanitary sewer model. Add ?format=inp to get the raw .inp file instead of JSON.

        
Request Body

        

          
ParameterTypeDefaultDescription

          
Ninteger200Number of junction nodes (10-10,000)

          
typestring"sanitary"sanitary, stormwater, combined, transport_only, rdii_calibration, pump_intensive, wos_intensive

          
unitsstring"US""US" or "SI"

          
terrainstring"flat"flat, moderate, hilly, mountainous

          
detailstring"basic"basic, moderate, detailed

          
landUsestring"residential"mixed, residential, commercial, industrial

          
outfallElevnumber0Outfall invert elevation

          
generationMethodstring"force_directed"Network topology algorithm (16 methods)

          
rainfallDiststring"scs-type-ii"Rainfall pattern ID (see /api/rainfall-patterns)

          
rainfallDepthnumber2.0Total rainfall depth (in or mm)

          
enableLIDbooleanfalseGreen infrastructure sections

          
enableWQbooleanfalseWater quality sections

          
enableSnowmeltbooleanfalseCold-climate sections

          
enableDividersbooleanfalseFlow-splitting dividers

          
enableStreetInletsbooleanfalseStreet inlet sections

          
enableCurvedLinksbooleanfalseVertex bend points

          
reswmmobject{enabled: false}ReSWMM discretization config

        

        
See GET /api/config-schema for the complete list of all parameters.

        /api/generate-and-simulate
        Generate an INP and run SWMM5 simulation
        ▶
      

      

        
Combines generation and simulation in a single request. Same configuration parameters as /api/generate. The response includes both the generated INP file and SWMM5 simulation results (continuity errors, warnings, report text).

        POST
        /api/transform
        Transform/anonymize an INP file
        ▶
      

      

        
Reads an existing INP file, renames all element names (nodes, links, subcatchments, rain gages, curves, etc.) using a consistent mapping, and optionally distorts geometry (coordinates, elevations, dimensions) via rotation, scaling, translation, mirroring, and jitter. Useful for anonymizing real-world models for sharing or publication.

ParameterTypeDefaultDescription

          
inpstringINP file content (required)

config.distortCoordinatesbooleantrueApply geometric transforms to coordinates

          
config.rotationnumber0Rotation angle in degrees (0-360)

          
config.scalenumber1.0Scale factor for coordinates (0.1-5.0)

          
config.translateXnumber0X translation offset

          
config.translateYnumber0Y translation offset

          
config.mirrorstring"none"Mirror axis: "none", "x", "y", or "both"

          
config.jitterCoordsnumber0Random jitter magnitude for coordinates

          
config.distortElevationsbooleanfalseApply transforms to elevations

          
config.elevationOffsetnumber0Elevation offset in model units

          
config.elevationScalenumber1.0Elevation scale factor

          
config.jitterElevationnumber0Random elevation jitter

          
config.distortDimensionsbooleanfalseScale cross-section dimensions

          
config.dimensionScalenumber1.0Dimension scale factor

Code Examples


    
Python

    
import requests

# Generate a 500-node stormwater model
response = requests.post("https://your-app.replit.app/api/generate", json={
    "N": 500,
    "type": "stormwater",
    "terrain": "hilly",
    "enableWQ": True,
    "enableLID": True,
    "rainfallDist": "scs-type-ii",
    "rainfallDepth": 3.0,
})
data = response.json()

# Save the .inp file
with open("model.inp", "w") as f:
    f.write(data["inp"])

print(f"Generated {data['stats']['junctions']} junctions, "
      f"{data['stats']['conduits']} conduits in {data['generationTimeMs']}ms")
print(f"Sections: {data['sectionCount']}/56")

# Generate and simulate in one call
response = requests.post("https://your-app.replit.app/api/generate-and-simulate", json={
    "N": 200,
    "type": "sanitary",
})
result = response.json()
print(f"Simulation: {result['simulation']['summary']}")



    
JavaScript / Node.js

    
const response = await fetch("/api/generate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    N: 1000,
    type: "combined",
    terrain: "moderate",
    enableSnowmelt: true,
    enableDividers: true,
    reswmm: { enabled: true, method: "fixed_interval", fixedMinLength: 50, fixedMaxLength: 200 },
  }),
});
const { inp, stats, sections } = await response.json();
console.log(`Generated: ${stats.junctions} junctions, ${stats.conduits} conduits`);
console.log(`Active sections: ${sections.length}/56`);
